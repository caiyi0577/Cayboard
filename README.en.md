# Cayboard

[简体中文](README.md) · [English](README.en.md) · [繁體中文](README.zh-TW.md)

Cayboard is an open-source Android keyboard for Chinese nine-key input, full Pinyin, double Pinyin, and English. It also supports physical keyboards.

For the same input method and code, the last successfully committed choice takes the first candidate slot. The long-term dictionary orders the remaining candidates.

Typing, handwriting, X-ASR speech recognition, and Hy-MT2 translation run on the device. The full APK bundles these models. Optional Nutstore backup uses WebDAV credentials you provide. The privacy policy under About describes data use and permissions.

Release pages list available APKs, installation instructions, and bundled models. [GitHub Releases](https://github.com/caiyi0577/Cayboard/releases)
