# Cayboard

[简体中文](README.md) · [English](README.en.md) · [繁體中文](README.zh-TW.md)

Cayboard is an open-source Android keyboard based on [CyIME](https://github.com/Cyletix/CyIME) and [Rime](https://rime.im/).

It focuses on nine-key Chinese input and also supports full Pinyin, double Pinyin, and English. Bundled dictionaries, handwriting, speech recognition, camera OCR, and multilingual translation run on the device.

The APK has no internet permission. The privacy policy under About explains local data, permissions, and exports you choose to make.
