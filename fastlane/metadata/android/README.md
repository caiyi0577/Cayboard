# 商店元数据（fastlane）

`title.txt` / `short_description.txt` / `full_description.txt` 使用 Cayboard 产品名称。

商店图标与截图应使用 Cayboard 自有品牌资源；Xime 的名称、Logo 与其他品牌资产不在 GPLv3 授权范围内（见 [TRADEMARKS.md](../../../TRADEMARKS.md)）。

- `images/icon.png`：应用图标（512×512 左右，F-Droid 元数据要求）
- `images/phoneScreenshots/0.jpg`、`1.jpg` …：手机截图，编号须从 0 开始连续

补齐前，商店元数据仅有文字描述，不影响仓库构建。
