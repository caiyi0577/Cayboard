# Cayboard

[简体中文](README.md) · [English](README.en.md) · [繁體中文](README.zh-TW.md)

Cayboard 是開源 Android 輸入法，主打中文九鍵，也支援全拼、雙拼、英文輸入和實體鍵盤。

相同輸入方式和編碼下，最近一次成功選中的詞排第一，第二位起由長期詞典排序。

輸入、手寫、X-ASR 語音轉文字及 Hy-MT2 多語翻譯在裝置上執行。完整版 APK 內建這些模型。堅果雲備份需主動設定 WebDAV 帳號和應用程式密碼。資料和權限說明見「關於 → 隱私政策」。

APK、安裝說明和內建模型清單可在版本發布頁查看。 [GitHub Releases](https://github.com/caiyi0577/Cayboard/releases)
