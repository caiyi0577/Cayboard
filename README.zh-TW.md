# Cayboard

[简体中文](README.md) · [English](README.en.md) · [繁體中文](README.zh-TW.md)

Cayboard 是一款基於 [CyIME](https://github.com/Cyletix/CyIME) 和 [Rime](https://rime.im/) 開發的開源 Android 輸入法。

主打中文九鍵，也支援全拼、雙拼和英文輸入。內建詞庫、手寫、語音轉文字、拍照辨識和多語翻譯，均在裝置上執行。

安裝包沒有連網權限。應用程式內的「關於 → 隱私政策」說明本機資料、權限及自行匯出的行為。
